# 🖥️ Архитектура аппаратных средств

> Репозиторий, посвящённый изучению архитектуры аппаратных средств вычислительных систем.

**Добро пожаловать!** 👋

Этот проект создан для того, чтобы собрать и систематизировать материалы, помогающие понять, как устроены вычислительные системы на аппаратном уровне и как их организация связана с работой программного обеспечения.

# Занятие 2. Логические операции и таблицы истинности

В работе разобраны логические выражения и побитовые операции в Python.

## Материалы

- [_logical_operations.pdf](_logical_operations.pdf) содержит таблицы значений трёх логических выражений для всех сочетаний входных данных.
- [experimental.py](experimental.py) показывает побитовые операции над целым числом.

## Работа с программой

Запустите программу и введите целое число:

```bash
python experimental.py
```

Программа выведет число в двоичном виде и результаты операций AND, OR, XOR, NOT, а также сдвигов влево и вправо. Для первых трёх операций второй операнд равен 1.

## Вывод

Таблицы истинности помогают проверить логические выражения, а программа показывает, как побитовые операции изменяют двоичную запись числа.

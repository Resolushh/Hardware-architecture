## Основные темы

* Назначение GPU, VRAM, питания и охлаждения.
* Отличия GPU от CPU, SIMT и варпы.
* Расчет пропускной способности видеопамяти.
* Передача данных от CPU к монитору.
* Использование GPU в играх и искусственном интеллекте.

## Вывод

GPU выполняет много похожих вычислений параллельно. Это полезно при обработке графики и работе нейросетей. Для RTX 3060 Ti с 8 ГБ GDDR6 рассчитана пропускная способность памяти 448 ГБ/с.
